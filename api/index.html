Pregnant_Sister adalah symmetric block cipher yang memakai Conway's Game of Life (cellular automaton). Setiap blok 256 bit melewati 18 ronde jaringan Feistel (2 ronde Game of Life + 16 ronde substitution-permutation gaya AES). Round key diturunkan dari kunci (minimal 32 byte) dan nonce acak 32 byte.

API ini berupa pustaka Python dengan dua fungsi: encrypt() dan decrypt(). Jalankan kode dari root repositori agar paket src dapat diimpor.

encrypt()


from src.encrypt import encrypt

key = "kunci-rahasia-minimal-32-byte!!!"
ct = encrypt("Halo, dunia!", key, mode="CBC")

print(ct)
# b'NW10XhnXn70ewiROtrNSWJD2RfetdMe+lp/5DIfC...'

Mengenkripsi data dan mengembalikan ciphertext dalam Base64. Nonce acak dibuat di setiap pemanggilan, jadi hasilnya selalu berbeda walaupun plaintext dan kuncinya sama.

encrypt(data, key, mode="CBC", nonce_size=32) -> bytes

INPUT

Parameter Tipe Keterangan
data str, bytes Plaintext. String di-encode dengan UTF-8.
key str, bytes Kunci rahasia, minimal 32 byte.
mode str (opsional - default: "CBC") Mode operasi: ECB, CBC, CFB, OFB, atau CTR.
nonce_size int (opsional - default: 32) Tidak dipakai, nonce selalu 32 byte.

OUTPUT

Tipe Keterangan
bytes Base64 dari nonce (32 byte) + ciphertext.

decrypt()


from src.decrypt import decrypt

pt = decrypt(ct, key, mode="CBC")

print(pt)                   # b'Halo, dunia!'
print(pt.decode("utf-8"))   # Halo, dunia!

Mendekripsi ciphertext hasil encrypt() kembali menjadi plaintext. Nonce dibaca dari 32 byte pertama ciphertext.

decrypt(data, key, mode="CBC", nonce_size=32) -> bytes

INPUT

Parameter Tipe Keterangan
data bytes, str Ciphertext Base64 hasil encrypt().
key str, bytes Kunci yang sama dengan saat enkripsi.
mode str (opsional - default: "CBC") Harus sama dengan mode saat enkripsi.
nonce_size int (opsional - default: 32) Panjang nonce di awal ciphertext.

OUTPUT

Tipe Keterangan
bytes Plaintext asli. Gunakan .decode("utf-8") untuk mendapatkan teks.

Errors

Exception yang dapat muncul dari encrypt() dan decrypt():

Error Penyebab
ValueError Kunci kurang dari 32 byte, atau kunci/mode salah saat dekripsi sehingga padding tidak valid.
TypeError Kunci bukan str/bytes, atau mode tidak dikenal saat enkripsi.
binascii.Error Ciphertext bukan Base64 yang valid.
IndexError Panjang ciphertext rusak (bukan kelipatan 32 byte) pada mode ECB atau CBC.

Catatan


# Contoh: enkripsi berkas dengan kunci acak
import secrets

key = secrets.token_bytes(32)
with open("test/berkas/image.jpg", "rb") as f:
    data = f.read()

ct = encrypt(data, key, mode="CTR")
assert decrypt(ct, key, mode="CTR") == data
  • Mode tidak disimpan di dalam ciphertext, jadi enkripsi dan dekripsi harus memakai mode yang sama.
  • Ciphertext tidak memiliki MAC, sehingga perubahan pada ciphertext tidak selalu terdeteksi.
  • Kunci yang lebih dari 32 byte dilipat dengan XOR menjadi 32 byte. Gunakan kunci acak 32 byte, misalnya secrets.token_bytes(32).
