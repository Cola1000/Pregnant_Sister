Mulai


from src.encrypt import encrypt
from src.decrypt import decrypt

key = "kunci-rahasia-minimal-32-byte!!!"   # 32 byte

ct = encrypt("My Sister is Pregnant, I'm gonna be a dad!", key)
print(ct)
# b'PS69/Knx2LHg2aIomY3MOmRSZOtyxZN3ukMZ...'
# (berbeda di setiap pemanggilan)

pt = decrypt(ct, key)
print(pt)                   # b'My Sister is Pregnant, I'm gonna be a dad!'
print(pt.decode("utf-8"))   # My Sister is Pregnant, I'm gonna be a dad!

Pregnant_Sister adalah symmetric block cipher 256 bit yang memakai Conway's Game of Life (cellular automaton). Setiap blok melewati 18 ronde jaringan Feistel: 2 ronde Game of Life dan 16 ronde substitution-permutation gaya AES. Round key diturunkan dari kunci (minimal 32 byte, di-hash dengan SHA-256) dan nonce acak 32 byte yang dibuat ulang di setiap enkripsi.

API ini berupa pustaka Python, bukan layanan HTTP. Antarmuka utamanya hanya dua fungsi: encrypt() dan decrypt(). Keduanya menerima teks maupun data biner, dan memakai mode CBC jika mode tidak disebutkan.

Spesifikasi Nilai
Ukuran blok256 bit (32 byte)
StrukturFeistel 18 ronde (Game of Life pada ronde 1 dan 18, SPN pada ronde 2–17)
KunciMinimal 32 byte, di-hash SHA-256 menjadi 256 bit
Nonce32 byte acak per enkripsi
Mode operasiECB, CBC (default), CFB, OFB, CTR
PaddingPKCS#7, kelipatan 32 byte
KeluaranBase64 dari nonce + ciphertext

Jalankan skrip dari akar/root repositori, yaitu folder yang berisi folder src (misalnya python skrip.py dengan skrip.py diletakkan di samping src), agar from src.encrypt import encrypt dapat diimpor. Test dijalankan dari folder yang sama, misalnya python -m test.test_security.

encrypt()


from src.encrypt import encrypt

key = "kunci-rahasia-minimal-32-byte!!!"

# teks
ct = encrypt("My Sister is Pregnant, I'm gonna be a dad!", key, mode="CBC")

# data biner
with open("foto.jpg", "rb") as f:
    ct = encrypt(f.read(), key, mode="CTR")

# simpan sebagai teks (Base64 aman untuk JSON/berkas)
with open("foto.jpg.enc", "wb") as f:
    f.write(ct)

Mengenkripsi data dan mengembalikan ciphertext dalam Base64. Nonce acak dibuat di setiap pemanggilan dan disisipkan di depan ciphertext, jadi hasilnya selalu berbeda walaupun plaintext dan kuncinya sama, dan nonce tidak perlu disimpan terpisah.

encrypt(data, key, mode="CBC", nonce_size=32) -> bytes

INPUT

Parameter Tipe Keterangan
data str, bytes, bytearray Plaintext. String di-encode dengan UTF-8. Boleh kosong.
key str, bytes, bytearray Kunci rahasia, minimal 32 byte (string diukur setelah di-encode UTF-8). Kunci sepanjang apa pun di-hash dengan SHA-256.
mode str (opsional - default: "CBC") Mode operasi: ECB, CBC, CFB, OFB, atau CTR. Tidak membedakan huruf besar/kecil.
nonce_size int (opsional - default: 32) Tidak dipakai; nonce selalu 32 byte. Biarkan default.

OUTPUT

Tipe Keterangan
bytes Teks Base64 (ASCII) dari nonce (32 byte) + ciphertext. Panggil .decode("ascii") jika membutuhkan str.

# berkas biner
with open("foto.jpg.enc", "rb") as f:
    data = decrypt(f.read(), key, mode="CTR")
with open("foto-asli.jpg", "wb") as f:
    f.write(data)

Mendekripsi ciphertext hasil encrypt() kembali menjadi plaintext. Nonce dibaca dari 32 byte pertama, round key diturunkan ulang, lalu padding dibuang dan divalidasi.

decrypt(data, key, mode="CBC", nonce_size=32) -> bytes

INPUT

Parameter Tipe Keterangan
data bytes, str Ciphertext Base64 persis seperti hasil encrypt().
key str, bytes, bytearray Kunci yang sama dengan saat enkripsi.
mode str (opsional - default: "CBC") Harus sama dengan mode saat enkripsi, karena mode tidak disimpan di ciphertext.
nonce_size int (opsional - default: 32) Panjang nonce di awal ciphertext. Harus 32.

OUTPUT

Tipe Keterangan
bytes Plaintext asli, selalu bertipe bytes. Gunakan .decode("utf-8") untuk mendapatkan teks.

Format ciphertext


import base64

raw = base64.b64decode(ct)
nonce, body = raw[:32], raw[32:]
blocks = [body[i:i + 32] for i in range(0, len(body), 32)]

# ukuran untuk plaintext n byte
# raw  = 32 + 32 * (n // 32 + 1)
# Base64  = 4 * ceil(raw / 3)

Nilai kembalian encrypt() adalah Base64 dari nonce (32 B) || C1 || C2 || ... || Cn, dengan setiap blok Ci berukuran 32 byte. Padding PKCS#7 selalu menambah 1–32 byte, jadi plaintext yang panjangnya tepat kelipatan 32 tetap mendapat satu blok padding penuh. Semua mode memakai padding, sehingga ukuran ciphertext sama untuk kelima mode.

Mode operasi


for mode in ["ECB", "CBC", "CFB", "OFB", "CTR"]:
    ct = encrypt(b"data", key, mode=mode)
    assert decrypt(ct, key, mode=mode) == b"data"

Nonce selalu dipakai untuk menurunkan round key. Pada mode selain ECB, nonce juga dipakai sebagai IV atau nilai awal counter. E adalah enkripsi satu blok.

Mode Enkripsi Catatan
ECBCi = E(Pi)Blok plaintext identik menghasilkan blok ciphertext identik. Hindari untuk data berpola.
CBCCi = E(Pi xor Ci-1), C0 = nonceDefault.
CFBCi = Pi xor E(Ci-1), C0 = nonceCFB blok penuh (256 bit).
OFBOi = E(Oi-1), Ci = Pi xor Oi, O0 = nonceEnkripsi dan dekripsi identik.
CTRCi = Pi xor E(nonce + i - 1)Nonce dibaca sebagai bilangan 256 bit big-endian.

Contoh penggunaan


import json
import secrets
from src.encrypt import encrypt
from src.decrypt import decrypt

# 1. Kunci acak yang kuat
key = secrets.token_bytes(32)

# 2. Mengirim ciphertext lewat JSON; simpan mode bersama ciphertext
payload = json.dumps({
    "mode": "CTR",
    "ciphertext": encrypt("rahasia", key, mode="CTR").decode("ascii"),
})
msg = json.loads(payload)
decrypt(msg["ciphertext"], key, mode=msg["mode"])   # b'rahasia'

# 3. Menangani dekripsi yang gagal
def safe_decrypt(ct, key, mode="CBC"):
    try:
        return decrypt(ct, key, mode)
    except (ValueError, IndexError) as e:
        raise ValueError("ciphertext, kunci, atau mode tidak cocok") from e

Kunci. Gunakan kunci acak 32 byte dari secrets.token_bytes(32) dan simpan dengan aman. Kunci berupa string juga diterima selama panjangnya minimal 32 byte.

Transport. Keluaran Base64 aman dimasukkan ke JSON, basis data, atau berkas teks. Mode tidak tercatat di dalam ciphertext, jadi simpan atau sepakati mode bersama ciphertext.

Dekripsi gagal. Kunci atau mode yang salah biasanya memicu ValueError dari validasi padding. Plaintext kosong juga terdekripsi menjadi b"", jadi jangan memakai nilai kosong sebagai penanda kegagalan; tangkap exception-nya.

Errors

Exception dan perilaku khusus dari encrypt() dan decrypt():

Kondisi Perilaku
Kunci kurang dari 32 byte ValueError: Key must be at least 32 bytes, didahului cetakan Error: invalid key.
Kunci bukan str/bytes TypeError: Key must be str or bytes.
Mode tidak dikenal encrypt(): TypeError. decrypt(): mencetak Unpad fail: data invalid dan mengembalikan b"".
Ciphertext bukan Base64 binascii.Error (turunan ValueError).
Kunci atau mode salah, atau ciphertext diubah Biasanya ValueError: Invalid padding .... Tidak dijamin: sekitar 1 dari 256 kasus menghasilkan data acak tanpa error.
Panjang ciphertext bukan kelipatan 32 byte ECB/CBC: IndexError. CFB/OFB/CTR: mencetak Unpad fail: data invalid dan mengembalikan b"".

Catatan keamanan


# Encrypt-then-MAC: tambahkan HMAC jika integritas dibutuhkan
import hashlib, hmac, secrets

mac_key = secrets.token_bytes(32)        # terpisah dari key
ct = encrypt(data, key)
tag = hmac.new(mac_key, ct, hashlib.sha256).digest()

# di sisi penerima
expected = hmac.new(mac_key, ct, hashlib.sha256).digest()
if not hmac.compare_digest(tag, expected):
    raise ValueError("ciphertext telah diubah")
pt = decrypt(ct, key)
  • Tidak ada autentikasi. Ciphertext tidak memiliki MAC, sehingga perubahan pada ciphertext tidak selalu terdeteksi. Tambahkan HMAC atas ciphertext (encrypt-then-MAC) dengan kunci terpisah jika integritas dibutuhkan.
  • Kunci. Kunci di-hash dengan SHA-256, jadi kunci panjang apa pun dipakai seluruhnya. SHA-256 bukan KDF kata sandi; jika kunci berasal dari kata sandi, turunkan dulu dengan PBKDF2 atau Argon2.
  • ECB. Round key berbeda untuk setiap pesan, tetapi blok identik di dalam satu pesan tetap menghasilkan ciphertext identik. Gunakan CBC atau CTR.
  • Mode. Mode tidak disimpan di ciphertext; pengirim dan penerima harus memakai mode yang sama.
  • Kinerja. Implementasi murni Python berjalan sekitar 60–70 KB/s, sehingga cocok untuk data hingga beberapa MB.
