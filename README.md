# Pregnant_Sister
Symmetric Key Cryptography Using Cellular Automaton

## Tech Stack
Python 3.13.

## Dependencies
matplotlib

## Cara Menjalankan
```bash
python -m venv ./venv
./venv/Scripts/activate
pip install -r requirements.txt
```

### Menjalankan Test
```bash 
python -m test.test_text
python -m test.test_image
python -m test.test_video
```
> Note: Ini dilakukan di root directory project
